# Convi

**Convi** — универсальный конвертер файлов для Windows с компактным круговым интерфейсом, инструментами обработки мультимедиа и автоматизацией конвертации.

Программа объединяет в одном приложении инструменты для работы с изображениями, видео, аудио, документами, таблицами, презентациями и другими форматами файлов.

> **Convi 3.2** — описание возможностей текущей версии проекта.

---

## Основные возможности

- Поддержка **871 расширения файлов** в различных категориях.
- Круговой интерфейс для выбора форматов.
- Определение некоторых файлов по содержимому, а не только по расширению.
- Предварительный просмотр файлов.
- История выполненных конвертаций.
- Автоматическая конвертация новых файлов в выбранной папке.
- Работа с буфером обмена.
- Настройки качества, места сохранения и поведения приложения.
- Работа через системный трей Windows.

Convi распознаёт и обрабатывает 871 файловое расширение. Возможности преобразования зависят от конкретного формата, доступных библиотек и установленных внешних компонентов.

## Интерфейс

Convi использует круговую систему выбора форматов, позволяющую быстро ориентироваться среди доступных вариантов.

В интерфейсе предусмотрены:

- выбор формата;
- подсказки и описания форматов;
- предварительный просмотр;
- индикация недавно использованных форматов;
- доступ к дополнительным инструментам;
- тёмная тема оформления.

---

## Работа с изображениями

Встроенные инструменты позволяют:

- конвертировать изображения между форматами;
- сжимать изображения по качеству или целевому размеру;
- изменять размеры и масштаб;
- поворачивать и отражать изображения;
- преобразовывать изображения в чёрно-белый формат;
- обрезать изображения с использованием пропорций;
- добавлять водяные знаки и подписи;
- удалять EXIF-метаданные;
- объединять изображения в PDF.

В зависимости от доступных библиотек поддерживаются форматы, включая JPG, PNG, WEBP, AVIF, BMP, GIF, TIFF, ICO и PDF.

---

## Работа с видео

Инструменты обработки видео включают:

- конвертацию видео;
- сжатие;
- уменьшение разрешения;
- настройку сжатия под целевой размер;
- обрезку видео;
- удаление аудиодорожки;
- преобразование видео в GIF;
- извлечение аудио из видео.

Среди поддерживаемых контейнеров и форматов: MP4, AVI, MKV, MOV, WEBM, WMV, GIF, MP3 и WAV.

---

## Работа с аудио

Convi предоставляет инструменты для:

- конвертации аудиофайлов;
- обрезки аудио;
- извлечения звука из видео;
- работы с различными аудиокодеками и контейнерами.

Поддерживаемые форматы могут включать MP3, WAV, OGG, FLAC, M4A, AAC, OPUS и WMA.

---

## PDF-инструменты

В приложении предусмотрены операции с PDF:

- объединение нескольких PDF-файлов;
- разделение документа на страницы;
- разделение по заданным диапазонам страниц;
- поворот страниц;
- сжатие PDF;
- преобразование страниц PDF в изображения.

---

## Документы

Convi поддерживает конвертацию текстовых и документных файлов в различные форматы, в том числе:

- PDF;
- DOCX;
- TXT;
- HTML;
- Markdown;
- RTF;
- JPG;
- PNG.

Для некоторых расширенных форматов может потребоваться LibreOffice или совместимое офисное программное обеспечение.

---

## Таблицы

Возможна конвертация табличных файлов в форматы:

- XLSX;
- CSV;
- PDF;
- HTML;
- JSON.

CSV-файлы по умолчанию используют разделитель `;`, что удобно для региональных настроек, распространённых в русскоязычной среде.

---

## Презентации

Презентации могут преобразовываться в:

- PDF;
- PPTX;
- TXT;
- DOCX.

Для некоторых операций может потребоваться LibreOffice или совместимое офисное ПО.

---

## Автоматическая конвертация папок

Convi может отслеживать выбранную папку и автоматически обрабатывать новые файлы.

Примеры использования:

- автоматически преобразовывать входящие изображения в JPG;
- конвертировать видео в выбранный формат;
- обрабатывать аудиофайлы по заданным правилам.

Автоматизация предназначена для обработки новых файлов в отслеживаемой папке.

---

## Буфер обмена

Convi поддерживает операции с буфером обмена:

- вставка файлов с помощью `Ctrl + V`;
- вставка изображений и скриншотов;
- доступ к инструментам буфера обмена через меню системного трея.

---

## История конвертаций

Программа сохраняет историю последних операций. Пользователь может просматривать выполненные преобразования, открывать результат и переходить к папке с файлом.

---

## Настройки

В Convi доступны настройки поведения приложения, включая:

- место сохранения результата;
- сохранение рядом с оригиналом;
- сохранение в отдельную папку;
- замену исходных файлов;
- качество JPG, WebP и AVIF;
- DPI для PDF и изображений;
- горячие клавиши;
- автоматическую конвертацию папок;
- поведение приложения.

---

## Системный трей

Convi может работать в системном трее Windows. Через меню трея доступны быстрые действия, включая конвертацию, настройки, историю, инструменты буфера обмена и журнал ошибок.

## Установка

### Автоматическая установка

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта.
3. Запустите `Установить и запустить.bat`.
4. Скрипт создаст виртуальное окружение, установит зависимости и запустит приложение.

### Ручная установка

```bash
git clone https://github.com/AVI-CON/Convi.git
cd Convi
pip install -r requirements.txt
python convi.py
```

## Сборка EXE

Для сборки Windows-приложения используйте:

```text
Собрать EXE.bat
```

Или PyInstaller с конфигурацией проекта:

```text
convi.spec
```

Готовая сборка обычно располагается в папке `dist`.
